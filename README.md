## 👨💻 About Me

I'm a fullstack developer who builds **business systems**, not just websites.

My focus is on software that runs behind the scenes of a real operation: transaction flows, data integrity, access control, and the small details that decide whether a system survives daily use or gets abandoned after a week.

I care about three things in every project:

- **Reliable data.** Numbers and calculations belong in the database, not floating around in the browser.
- **Strict typing.** Type-safe code catches mistakes before users ever see them.
- **Real users.** The cashier, the admin, the teacher. If they can't use it comfortably, the system failed.
